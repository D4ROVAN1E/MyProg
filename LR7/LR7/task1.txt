Тебе необходимо написать рекурсивную программу решения поставленной задачи.
Напиши консольное приложение на языке C++, которое будет запрашивать у пользователя число n, и на его основе строить Треугольник Серпинского. Процесс его построения выглядит следующим
образом:
1. Строится равносторонний треугольник.
2. Середины сторон этого треугольника соединяются отрезками, тем самым образуя 4 новых треугольника.
3. Из исходного треугольника удаляется срединный треугольник, тем самым получая множество, состоящее из 3 оставшихся треугольников.
4. Повторить шаги 1-3 для каждого из трех получившихся треугольников 
При n = 0 получаем полностью закрашенный треугольник. При n = 1 получаем треугольник, внутри которого находится один пустой и три небольших. И так далее для разных n.
Программа должна уметь рисовать построенный треугольник.
