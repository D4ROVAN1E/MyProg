# Тест Миллера на простоту

## Основа теста
Тест Миллера основан на теореме Сэлфриджа и используется для проверки чисел на простоту.

## Алгоритм построения простого числа
1. **Подготовка таблицы простых чисел**:
   - Строится таблица малых простых чисел qᵢ (или используется готовая таблица).

2. **Формирование числа m**:
   - Строится число вида:  
     m = q₁^α₁ * q₂^α₂ * ... * qₖ^αₖ,  
     где qᵢ — различные случайные простые числа из таблицы,  
     αᵢ — случайные целые числа.  
   - Размер числа m должен быть на 1 бит меньше требуемого размера для искомого простого числа.

3. **Вычисление кандидата n**:
   - Вычисляется значение:  
     n = 2m + 1.

4. **Проверка числа n**:
   - Число n проверяется тестом Миллера с заданным параметром надежности.  
   - Если проверка не пройдена, процесс повторяется с шага 2 для построения нового числа m.

## Тест Миллера

**Входные данные**:
- `n` — число для проверки на простоту;
- `n−1 = q₁^α₁ * q₂^α₂ * ... * qₖ^αₖ` — каноническое разложение числа `n−1`;
- `t` — параметр надежности (количество проверок).

**Шаги алгоритма**:
1. **Выбор случайных чисел**:
   - Выбрать `t` различных случайных целых чисел aⱼ, где 1 < aⱼ < n.

2. **Проверка малой теоремы Ферма**:
   - Для каждого aⱼ вычислить aⱼ^(n−1) mod n.  
   - Если хотя бы один результат не равен 1, вернуть: «n — составное число».

3. **Дополнительные проверки**:
   - Для каждого простого множителя qᵢ из разложения `n−1`:
     1. Вычислить для каждого aⱼ значение aⱼ^((n−1)/qᵢ) mod n.  
     2. Если все результаты равны 1, вернуть: «Вероятно, n — составное число».  
     3. Если хотя бы один результат не равен 1, перейти к следующему qᵢ.

4. **Завершение**:
   - Если все проверки пройдены, вернуть: «n — простое число».  

**Выход**: Результат проверки числа `n` на простоту.
